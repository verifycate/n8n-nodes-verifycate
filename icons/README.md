# Icon

`verifycate.svg` is the Verifycate badge mark used on the website and social
profile. `verifycate.dark.svg` is the same mark for dark surfaces.

The Instagram profile image at
`~/Documents/Social/Verifycate/instadp.png` is the raster source for the mark.
n8n requires an SVG icon, so this package uses the vector version of the same
badge rather than the raster DP.
